# 📅 Day 2 - Understanding Data Types and How to Manipulate Strings

## 🚀 Overview
On Day 2 of my #100DaysOfCode challenge, I built a **Tip Calculator** using Python.
This project focuses on understanding **data types** and how to manipulate strings in Python.

## 📚 Concepts covered in this project:
- Python Primitive Data Types
- Type Error, Type Checking and Type Conversion
- Data Types
- Mathematical Operations in Python
- Number Manipulation and F Strings in Python

## Tip Calculator 💰
## 🛠 How It Works
1. The user inputs the total bill amount
2. The user inputs the percentage tip they want to give
3. The user inputs the number of people to split the bill
4. The program calculates the amount each person should pay and displays it
