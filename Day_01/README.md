# Day 1 - Working with Variables in Python to Manage Data

## 🚀 Overview
On Day 1 of my #100DaysOfCode challenge, I built a **Band Name Generator**.

This project focuses on understanding **variables** and how to manage data in Python.

## 📚 Concepts covered in this project:
- Printing to the Console in Python
- String Manipulation and Code Intelligence
- Debugging
- The Python Input Function
- Python Variables
- Variable Naming Conventions

## Band Name Generator 🎸
## 🛠 How It Works
1. The user is prompted to enter the name of their city
2. The user is prompted to enter the name of their pet
3. The program combines the city and pet names to generate a band name
